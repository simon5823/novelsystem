# 開發日誌｜2026-09-02

版本：**v1.0**

本機長篇／系列小說寫作工具「墨卷 NovelSystem」第一個可交付版本。資料只存在本機 SQLite，不連線呼叫模型。

---

## 今天做了什麼

### 1. 從需求到規格

與使用者對齊寫作工具範圍：章節字數、大綱、線索與伏筆、世界觀、人物卡、地圖、行為推演、校稿、寫作區自動更新。

拍板：

- 存檔先成功；校稿與資料變更需確認（後改為不連 API，校稿改用網頁版 Grok）。
- 全書共用時間軸；場景為最小單位。
- 地圖併入世界觀，釘圖與推演列第二期。
- 本機桌面、資料不上傳。

### 2. 第一期骨架

- 因本機無 Rust，改以 **Electron + React + TypeScript + SQLite（sql.js）** 實作。
- 作品＝一個資料夾＋`project.sqlite`。
- 寫作區、卷／章／場景、人物、世界、線索、詞彙、時間軸、版本快照、匯出 Markdown。

### 3. 寫作體驗

- 寫作改為獨立頁；場景用頂部標籤，可新增、刪除、拖曳排序。
- 對齊 Scrivener／Dabble／Ulysses：左側目錄、居中稿紙、檢查器、卡片總覽、專注模式。
- 圖示工具列：復原、重做、尋找、上一場／下一場、儲存、縮放等。

### 4. 拿掉雲端審閱

刪除 API 金鑰、審閱管線、待確認變更。儲存只做本機保全與版本紀錄。

### 5. 聖經各頁收斂

- **人物**：頭像列、總覽卡、關係圖（可拖圓點）。
- **時間軸**：拖曳調整先後、插入新時刻；可篩選並點場景跳回寫作。
- **世界**：分類側欄＋清單／詳細表單，拿掉瀏覽器彈窗。
- **線索**：情節表（列＝線索、欄＝時刻）。
- **詞彙**：自訂種類、分組、拖曳歸類、搜尋與編輯。
- 儲存正文時，依提到的人名／地名同步在場、經歷、線索節點。

### 6. 系列結構

最外層加上「部」：

`系列 → 部 → 卷 → 章 → 場景`

人物／世界／時間軸／線索／詞彙全系列共用。舊作品開啟時自動歸入「第一部」。

### 7. 用語

介面改為臺灣繁體中文習慣：儲存、人物、作品、詞彙、說話習慣、身分、場景、回收筒等。
