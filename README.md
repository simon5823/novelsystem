# 墨卷 NovelSystem

版本 **v1.0**（2026-09-02）

本機長篇／系列小說寫作工具。手稿與故事聖經只存在你選擇的資料夾，**完全離線、不呼叫任何 API**。

開發日誌見 `docs/開發日誌-2026-09-02.md`。

寫作頁對齊 Scrivener／Dabble／Ulysses 的習慣：左側稿件目錄、中間一次只寫一場、頂部用場景標籤切換。

## 啟動

```powershell
cd F:\NovelSystem
npm install
npm run dev
```

## 寫作頁

- 左側「稿件」只列卷／章；場景改在編輯區頂部的**標籤列**。
- `+` 在目前場之後新增場景；標籤上的 `×` 刪除該場。
- 一次只編一場，版面是居中稿紙（類似 Ulysses）。
- 「場次」打開右側檢查器：時間、地點、視角、在場、線索。
- `Ctrl+S` 存檔並留版本快照；輸入時會自動保全草稿。
- `Ctrl+Shift+F` 專注寫作（隱藏目錄與檢查器）。

校稿請用網頁版 Grok。此軟體不連模型。

## 建議確認路徑

開啟 `F:\NovelSystem\examples\qingyun`。

1. 《山門夜雨》頂部應有兩個場景標籤，點標籤只顯示該場正文。
2. 按 `+` 出現第三場；用 `×` 刪掉。
3. 角色／世界／線索／時間軸資料仍在。
4. 存檔、版本還原、匯出 Markdown 可用。
